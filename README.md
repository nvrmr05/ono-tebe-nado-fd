# Оно тебе надо

Вёрстка лендинга аукциона «вещей, в которые никто не верил»: фильмов, книг и картин, которые когда-то не приняли критики, а теперь они стали культовыми.

Проект свёрстан по макету и сверен с ним попиксельно.

## Технологии

- HTML5 (семантическая разметка)
- CSS3: Flexbox, Grid, `object-fit`, `filter`
- Шрифт Raleway

## Структура страницы

1. **Шапка**: навигация, логотип по центру и контакты.
2. **Обложка**: заголовок «Оно тебе надо» лесенкой, подзаголовок и кнопка «Сделать ставку».
3. **Лоты**: три карточки с фоновыми изображениями и описанием, ссылка «посмотреть больше».
4. **Об аукционе**: логотип в круге и описание проекта.
5. **Футер**: контакты, меню и ссылки на соцсети.

## Структура файлов

```
├── index.html
├── css/
│   └── style.css
├── images/
└── README.md
```

## Особенности вёрстки

- Шапка и футер построены на CSS Grid (`1fr auto 1fr`). Поэтому центральный элемент стоит ровно по центру страницы независимо от ширины боковых блоков.
- Заголовок на обложке выстроен лесенкой через `align-self`. Отрицательный `margin-right` компенсирует разрядку после последней буквы, чтобы слова точно выравнивались по краю.
- Изображения в карточках лотов затемнены через `filter: brightness()`, чтобы белый текст поверх них читался.
- Вёрстка сверена с макетом с помощью PixelPerfect.

## Как открыть

1. Скачать или клонировать репозиторий.
2. Открыть `index.html` в браузере.
